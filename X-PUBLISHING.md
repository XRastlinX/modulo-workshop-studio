## Package fields

| Field | Purpose |
|---|---|
| Title and opening | One concrete question and a reason to read |
| Why this matters | Reader consequence, stated without growth guarantees |
| Small demonstration | A worked example with retained assumptions and source data |
| What was checked | Actual observations, separated from claims and analogies |
| What would count against it | Counterexample or implementation failure predicate |
| Whose work it touches | Original sources and dependencies, with links |
| What remains open | Limits, missing checks and unresolved questions |
| Git reference | Repository plus a relevant commit or file |
| Companion text | A concise standalone introduction with a link after publication |

The first candidate is “The Universe Returned a Remainder. Please Retain Your Workings.” Its sources are standard Euclidean division, Python divmod and this repository's recorded implementation checks. It claims neither a new theorem nor a solution to P versus NP. Its live draft is https://x.com/compose/articles/edit/2115008898847424512 (account access required).

The human-facing interface is X → More → Articles → draft → Preview → Publish. An article can include linked sources and media. No API automation, account upgrade or subscription purchase was performed. No existing drafts were edited.

Official source consulted: https://help.x.com/en/using-x/articles . Current documentation lists eligible subscription tiers, rich media, formatting and the Articles editor. Account-specific availability here is supported by the observed editor and saved draft, not by a subscription assumption.
