# Community identity and profile post

Candidate community: r/ModuloWorkshop. Public description:

Soft tek, agent tools and small demonstrations for complicated ideas. A workshop for inspectable Git blueprints, MP4 explainers, experimental interfaces and coded music. Every project asks: why does this matter, what would count against it, and whose work does it build on?

## Reddit profile post

Title: Modulo Workshop: a Git + MCP + MP4 studio for showing the workings

I'm putting together Modulo Workshop: a place where a hunch becomes a small experiment, a readable build brief and a demonstration someone else can inspect.

The first starter combines Git, a local MCP server and a Python/FFmpeg MP4 renderer. Its example is deliberately small: why does 10 + 5 land at 3 on a twelve-position dial? The video keeps the whole turns and total visible, so the remainder never silently replaces the original number.

The Git blueprint is here: https://github.com/XRastlinX/modulo-workshop-studio

There is also a Discord bot adapter with /modulo, /demo and /blueprint. It is not connected to a live server yet. The shared-command experience is part of the idea: ask for a bounded demonstration, see the result, examine the workings. Broader natural-language agent building remains a design question.

Each episode record asks:
- What is the question, and why does it matter?
- What does the demonstration actually check?
- What result would count against its claim?
- Whose work and which sources does it touch?
- What remains unresolved?

This is also space for music and esoteric imagery, with artistic interpretation identified as such. Complicated ideas can have several approachable examples without pretending those examples solve the whole problem.

The tone: a slightly bewildered cosmic workshop with receipts. The practical aim: ideas that another human or AI can examine and develop from an explicit brief.

The repository documents the implemented starter and its limits. No live Discord deployment or automatic social publication is claimed.
