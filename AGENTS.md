# Contributor contract

This repository is an inspectable starter. Preserve original sources, distinguish analogies from results and keep unresolved questions explicit. Do not infer publication or account-change permission from this file.

The mathematical kernel is integer arithmetic. Keep model changes separate from presentation changes. Required checks: unit tests, actual MCP stdio smoke check, media metadata check for renderer changes. Report exactly what was checked. Do not label an offline import as a live Discord test.

Never place tokens, account exports, unrelated archives or private posts in Git. No arbitrary shell or code execution endpoint belongs in the Discord adapter. The existing user allowlist and guild boundary must remain explicit.

Plans, walkthroughs and handoffs require a visual anchor identifying artifact, scope, state, topology, implemented versus proposed paths, effect boundaries, open residuals and a textual equivalent. Preserve available source identifiers/hashes. Visuals carry no verification or authority.

Future recommendations declare one vocational verb from STAGE, STRUCTURE, DRAFT, PROVISION, ASSEMBLE, and recommendation_effect: ADVISORY_ONLY; automatic_execution: FORBIDDEN; residual_posture: OPEN_ACKNOWLEDGED; sovereign_boundary: EXTERNAL_HUMAN_DISPOSITION_REQUIRED; authority_effect: NONE. Generation != Verification != Authorization != Execution. Crown remains detached.
